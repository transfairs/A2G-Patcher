For Anstoss 2 Gold · Original, GOG & 2007 CD

Anstoss 2 Gold,
the way it should be.

One small window, a few switches: the arrow buttons keep counting, the World Cup, European Championship and final videos no longer crash the game, nothing freezes after Windows has run for weeks, the sound comes out of the right device, and if you like, the goal limit goes up to 15. The GOG and 2007 releases also get patch 1.01, the GOG release gets its dialogs back, and its copy protection no longer turns your save into a “Raubkopie” (pirated copy). No compatibility mode needed, and every change can be taken back.

01The patches

Groups in the window: under Patches, the “Spielfehler” switch fixes sixteen of the game's bugs at once; next to it are patch 1.01 and the patches against crashes and problems with current Windows (videos, audio device), the outro under VMware and the upper limit for the bank balance. Balancing changes how the game plays. Under Texte are the euro, today’s names and terms and the quiz questions, for every release. Four more patches are for the GOG release only.

Game bug

Investments no longer drain the balance

Every gain of an investment is taken off the bank balance: the better it does, the less money is in the account, and the less interest it earns. Only closing it brings everything back at once, which looks like double interest. With the patch the balance only goes down by the money paid in, and the gain arrives once when the investment is closed.

Game bug

Events do what their message says

Some random events do something else than their message says. The free copier costs money, the prize draw brings some; the cups of a fan club tournament are booked as income, the sale of a plot and the fans' collection of donations as expenses. A won negotiation with the chocolate maker brings only the plain amount instead of the double one offered. Four messages announce that a player loses freshness points, but he gains them. And the hints for the co-trainer, after which players gain a form point, come with the sound for bad news. A concussion in training hurts the other of the two players named, fish poisoning shows as an injury without a name, a player growing old gets someone else’s question appended to his message, and after a riot that costs the club a lawsuit the game reports all calm. A bonus from the board promises every player a form point, a slip on a banana skin costs one, but neither happens. And two of the reasons meant to hold up the stadium works never come: a fans’ blockade and bad weather. With the patch everything matches the message.

Game bug

No crash on events without a fitting player

Some random events draw a player and use him without checking that one was found, for instance when the one drawn is on loan. The game then crashes. With the patch the event doesn’t happen.

Game bug

Referees with a grudge hit the right club

A referee can hold a grudge against a club, for instance after the manager insulted him in front of a microphone. In league matches he then shows that club’s players more cards, as intended. The match scenes he decides, though, compare the grudge with the club’s number plus one, so they hit the club with the next lower number and never the one with number 0. With the patch they hit the club he holds the grudge against.

Game bug

Trainers and managers in weak countries get better

Once a year the game raises every tenth trainer or manager by 1 or 2 points in countries where their average competence is below 6, but it never stores the new value. With the patch they keep it; the cut in countries with an average above 10 already works.

Game bug

Appearances without a mark don't count in the average

A player who plays less than 20 minutes gets no mark. If he gets a card, the season average in his details and the fans' check for a hated player count that appearance as mark 0, better than a 1. With the patch only marks count, as in the team statistics. The axis of the grade chart in the statistics also reads “Noten/6” (marks) instead of “Formpunkte/6” (form points), the label of the form chart.

Game bug

The list of most appearances takes in new players again

The club list of the players with the most appearances holds 50 players. A player who leaves the club still counts as one of its players there; once 50 players have played for the club, nobody new gets in, and the list stays as it is for good. With the patch the mark follows the squad again, and even a list frozen already takes in new players from the next match. A new player pushes out the former player with the fewest appearances; the first 20 places always stay, the other 30 leave room for a full squad. Appearances that were never counted don’t come back.

Game bug

Squads no longer grow beyond 30 players

A club with players on loan can get a 31st player, who overwrites the data behind the squad. The patch also counts the actual players when checking “squad full?”.

Game bug

Readable club names in the cup draw

On current Windows and under Wine, the club names in the cup draw video come out twice as wide, half as high and dotted, because the game expects a picture with 16 bits per pixel and gets 32. The patch asks for the picture in 16 bits explicitly.

Game bug

“A/B” and “i” buttons in their place

Picture buttons take their size from memory they never cleared before their picture is loaded. In the team lineup before a match, “A/B” and “i” are placed by that size and, with old data there, end up shifted or off screen. Seen under Wine; on Windows that memory is usually 0, the patch makes sure.

Game bug

No hang when opening the calculation screen

The preseason calculation screen takes one of its two selections from memory it never cleared. If a large value is there, the screen stays invisible and the game waits for it. Seen under Wine; on Windows that memory is usually 0, the patch makes sure.

Game bug

No false “disk almost full” warning

The game computes the free space in 32 bits. On large disks the calculation overflows, and now and then saving brings up the warning that the disk is almost full, for no reason.

Game bug

Arrows keep counting while held down

On current Windows, the arrow buttons for numeric values count one or two steps and then stop. Until now the only cure was the “Windows 98” compatibility mode. With the patch they simply keep counting.

Game bug

Desktop resolution restored, even after a crash

The game switches the screen to 640×480 in a way that outlives a crash. With the patch, Windows restores the resolution itself as soon as the game ends. The GOG release already gets this right; there the switch is greyed out.

Game bug

No freeze after more than 24 days of Windows uptime

A 3-second pause turns into weeks once Windows has been running for more than 231 ms. That comes sooner than you think: Windows Fast Startup keeps the uptime across a shutdown.

Game bug

Typing errors in the texts

When a player learns a new main position, the game reports something like “er ist nun rechter Verteidiger..”. Also a doubled “mehr”, a comma at the start of a sentence, missing full stops, “das” for “daß”, “UEFA - Pokals” and the cut heading “Europäischer Superc.”. The patch corrects them.

GOG & 2007 CD

Patch 1.01

The run.exe of GOG and that of the 2007 CD are built from version 1.00. The patch brings program and data up to the official patch 1.01, which the 1999 release already has: the training camp in the winter break, player lists, new players and goalkeepers, counters, event texts and more.

Patch

No crash on the World Cup, European Championship and final videos

After winning the World Cup the game crashes, because Windows no longer knows the video format of WM.AVI, EM.AVI and FINALE.AVI. The patch skips the video and the game goes on. With an Indeo codec installed, the videos play as before.

Patch

Sound on the Windows default audio device

The game takes the last sound device it finds instead of the one set in Windows. With monitor speakers and a headset, the sound easily ends up on the wrong one. With the patch it comes out where Windows sends it.

Patch

The outro at the right speed under VMware

Under Windows 98 in VMware (Sound Blaster 16), the outro shown when the game ends ran through in 40 instead of 80 seconds, its sound rushed. The game leaves DirectSound in 8-bit format; after that, the next sound through the normal Windows audio plays twice as fast. With the patch the game sets the sound to the format of its music when it starts, 16-bit stereo. The exe keeps its size, so A2G-Trainer still recognises it.

Patch

The bank balance no longer flips into the red

The game keeps a club’s money in a 32-bit number. Past 2,147,483,647 DM a good week turns it into about −2.1 billion, and the club counts as broke: overdraft interest, a forced loan. With the patch the club’s account stops at 2 billion DM; whatever comes in beyond that is lost.

−2.1 bn→2 bn
Balancing

The negotiation block wears off

After three negotiation dates with players of the same club, you are told that club would release no one “under any circumstances”. The block is meant to ease every month, but the game halves the wrong values, so it lasts until the next season. With the patch you can talk to that club about its players again after a month or two.

Balancing

Interview answers take effect

Every answer in an interview is meant to do something: more or fewer fans, a happier or angrier board, the team’s morale or a fine. But the game reads the answers from a place they are never written to, so none of them has any effect. With the patch they do what their texts promise.

Balancing

Raise the goal limit to 15

The game lets a team score only while it has fewer than 6 goals up to half-time and fewer than 10 after, and halves its chances from 7 goals on. The patch raises the limit to 15 and drops the brake.

10→15
Balancing

Unfitting speeches weaken the team

The game’s help warns that a pre-match speech that doesn’t fit the situation can turn its effect into the negative. But the game only shows a message and takes the use. With the patch such a speech costs the team its percentages in defence and attack for that match: “+3 %” becomes −3 %. A failed roll against the motivation skill stays without effect.

Balancing

Trainer supply

When a trainer or manager retires, a former player from a waiting list takes his place. But players only get on that list if they end their career at 36 or later, which outfield players rarely do. With the list empty, the retired one comes back under his name, aged 30 with competence 2; in the long run the strong trainers die out. With the patch former players get on the list from age 33, and without one the newcomer starts with competence 3 to 11, most often around 7. So trainers with competence 15 keep coming in the long run. This also goes for co-trainers and goalkeeper trainers.

Balancing

Fish poisoning: three weeks as reported

After the tuna pizza the game reports the player out for three weeks. What it enters, though, is a fish poisoning with the usual 7 days. With the patch he misses the three weeks.

Balancing

More events around the manager

The events of the manager’s private life are drawn from the wrong table, so 25 of their 39 cases never come. With their own table they join in: suspicion of rioting with hooligans, a national order, a book of his own, a microphone that records every word, and fans honking at night or throwing tomatoes while the board has little trust in the manager. The known ones come less often.

Six cases had no working code in the game and get it: a panel debate about standing room, an anonymous caller who, paid from the manager’s own money, offers to wreck the office of another human player’s club, an inheritance of 100 shares of the arch rival, respect from a journalist who can’t stand the manager, the vote for player of the month among the three best players of the last four match days, and an affair with the wife of a referee, who then holds it against the club.

No copy protection penalties

GOG sells the 2007 release, taken out of its copy protection. What is left of it still strikes: from the second season all clubs are called “Raubkopie” (pirated copy), players drop to strength 1, and ten self-checks of run.exe fail. With the patch all checks pass.

Dialogs as in the 1999 original

In GOG’s RESDLL.dll, 342 dialogs lack their title bar and 68 controls their sunken frame, such as the choices that look like buttons. The patch gives them back the styles of 1999.

GOG only

No black line on the animations

GOG’s DirectDraw wrapper (ddraw.dll) shows a black line along the right and bottom edge of the animations, such as the overhead kick in the main menu. The patch fills it with the picture. Offered only with GOG’s ddraw.dll in the game folder.

GOG only

No delay after mouse clicks

When the graphics driver doesn’t report a certain capability, GOG’s ddraw.dll takes a slow way of its own, and the game answers every click two to three seconds late (seen with a Radeon RX 6800 XT). The patch changes the ddraw.dll; without the delay it makes no noticeable difference. Offered only with GOG’s ddraw.dll in the game folder.

02How to

  1. Close the game.A2G-Patch changes nothing while Anstoss 2 is running.
  2. Start A2G-Patch.exe.From anywhere. It offers its own folder and the installed CD and GOG releases; Durchsuchen … (Browse) picks another game folder.
  3. Switch on, then Übernehmen (Apply).Switch on the patches you want, switch off the ones you no longer want. Done.

What happens

Original (1999)anstoss2.exe

The game file is changed directly. First, A2G-Patch puts a backup anstoss2.exe.vor-a2g-patch next to it. Once all patches are switched off again, the file is byte for byte as before and the backup goes.

GOGrun.exe

The same, with run.exe.vor-a2g-patch. The GOG patches also change RESDLL.dll (backup next to it) and the data files of patch 1.01; switching them off restores them too. A file check in GOG Galaxy restores the original; then simply apply again.

2007 CDrun.exe (packed)

The program code is only stored encrypted on disk. So A2G-Patch puts an msvfw32.dll into the game folder, which changes the code in memory at every game start. A2G-Patch changes the data files of patch 1.01 directly. Switching off all patches deletes the DLL again.

Texts, every releaseRESDLL.dll

The switches under “Texte” and the typing errors change RESDLL.dll, the event texts, the tips and the quiz directly, without a backup. Switched off, the files are byte for byte as before.

03Good to know

Why does A2G-Patch ask for administrator rights?

If the game is installed under “Program Files”, only an administrator may write there. A2G-Patch then offers to restart itself as administrator.

My virus scanner flags msvfw32.dll.

Some scanners react to an unsigned DLL in a game folder that has the name of a system DLL; malware uses the same trick. The DLL passes every call on to the real msvfw32.dll of Windows and only changes the game’s code. The source code is open in dll/msvfw32.c.

A switch is greyed out.

Each patch finds its places by the instructions around them. If it doesn’t find them exactly once, in the original or the patched state, A2G-Patch doesn’t offer it instead of blindly overwriting something. The switches under “Nur für die GOG-Version” (GOG release only) are only there if the files are exactly GOG’s.

There is already another msvfw32.dll in the game folder?

A DLL that doesn’t come from A2G-Patch is never touched. One from another version of A2G-Patch is replaced on Übernehmen (Apply).

Does it work with A2G-Trainer?

Yes. The Spielmechaniken switches in A2G-Trainer lift the goal limits and let the interview answers take effect while the trainer runs. Both recognize when A2G-Patch has already done so for good.

Is there a dark window?

Yes. Darstellung at the top of the window picks light, dark or Wie Windows (the default), which follows Windows' app mode, also when it is switched while the window is open.

04Under the hood

For the curious: what exactly happens in the machine code. The same patterns apply on disk (Patches.cs) and in memory (dll/msvfw32.c).

ArrowsA race between two threads

While a button is held, a thread posts one step to the window every 60 ms, but only while none is pending (+0xF4 == 0). It marks the step pending only after PostMessageA. On Windows NT the window is often faster, still finds a 0 while handling the step, and then the thread writes a 1 that is never taken down again. The patch marks the step pending before posting, in the same 41 bytes:

; before
mov eax,[msg] / mov ecx,[esi+1C] / push 0 / push 0 / push eax / push ecx / call ebx
mov eax,[esi+F4] / mov [esi+F0],60 / inc eax / mov [esi+F4],eax
; after
mov [esi+F4],1 / mov [esi+F0],60
mov eax,[msg] / mov ecx,[esi+1C] / push 0 / push 0 / push eax / push ecx / call ebx
nop / nop / nop / jmp next
VideosA missing NULL check

The videos are Indeo 3.2, which current Windows no longer decodes. The game’s video player doesn’t check the result of AVIStreamGetFrameOpen and then reads through a NULL pointer. The patch adds the check and on NULL takes the path the game takes anyway for a missing file. The room for it comes from a more compact encoding of the instructions before, in the same 75 bytes:

push [edi] / call AVIStreamGetFrameOpen / test eax,eax / jnz ok
mov [edi],eax / jmp release   ; skip the video
ok: mov [edi-8],eax
Goal limitsTwo brakes in the match engine

The limit becomes a fixed value, the halving is skipped. More than 15 isn’t possible: the game stores results and half-time scores as a 4-bit value per team.

limit:  setg r8 / dec r32 / and r,-4 / add r,10  →  setg r8 / mov r32,15 / nop …
brakes: jle (7E)                                  →  jmp (EB)
FreezeA signed comparison

A reply sequence waits up to 3 seconds and compares the difference of two timeGetTime values with sign. Once Windows has run for more than 231 ms, the difference turns negative and Sleep gets a huge wait time. The patch compares without sign, at both places:

sub eax,[ebp+17C] / cmp eax,0BB8 / mov [ebp+17C],eax / jge (7D)  →  jae (73)
Sound deviceThe wrong GUID

While enumerating, the game remembers the device with the most 3D buffers. Since Vista all report 0 there, on a tie the last one wins, and its GUID goes to DirectSoundCreate. With NULL, DirectSound takes the Windows default device:

push &guid (68 xx xx xx xx)  →  push esi / nop ×4   ; esi is 0 here
Outro speedThe primary buffer stays at 8 bits

The game opens DirectSound at the normal cooperative level; the primary buffer then keeps DirectSound’s default of 8 bits. With VMware’s Sound Blaster 16, the next sound through waveOut then runs on a clock twice as fast, the outro among them (EXTRO.AVI through MCIWnd). The patch rewrites the 121 bytes behind DirectSoundCreate: GetCaps fills its structure completely anyway, and a failed SetCooperativeLevel takes the identical way out right in front. The room this frees is enough for the primary buffer:

SetCooperativeLevel(hwnd, NORMAL)  →  (hwnd, PRIORITY)
                                       CreateSoundBuffer(primary) / SetFormat(22050 Hz, 16 bits, stereo) / Release

The buffer description and the format (38 bytes) go into zeros behind the end of .rdata (1999) or into the import section (GOG); taking the patch back zeroes them again.

Disk warningA 32-bit overflow

The game multiplies the values from GetDiskFreeSpaceA in 32 bits. On large disks the result is the free space modulo 4 GB and now and then falls below the threshold of 1.5 MB. The patch skips the warning; the game saves anyway:

cmp eax,177000 / jae (73)  →  jmp (EB)
SquadLoans count as departures

In many places the game checks whether a squad is full only by a forecast in which a player on loan counts as gone. So a 31st player fits in and is written behind the 30 slots. The patch also checks the actual squad size, in the same 32 bytes of the function:

full = forecast >= 30  →  full = forecast >= 30 or squad >= 30
ResolutionA missing flag

The game calls ChangeDisplaySettingsA with flag 0, so the change isn’t tied to the process. With CDS_FULLSCREEN it applies to the game only, and Windows restores the resolution when the game ends, even after a crash:

mov [esi+1C8],ebx (field is 0 already)  →  mov byte [esp+4],4 / nop
Cup draw32 instead of 16 bits per pixel

The video draws the club names with GDI into a 128×32 CreateCompatibleBitmap and reads them out with GetBitmapBits as a 16-bit picture. On current Windows and under Wine that bitmap has 32 bits per pixel even in the game’s 16-bit mode, so the game gets the upper half with each pixel split in two. The patch sends the call to added code that fetches the picture with GetDIBits explicitly in 16 bits and converts 5-5-5 to 5-6-5 where needed:

call [GetBitmapBits]  →  call helper / nop
helper: GetDC / GetDIBits(…, 128×-32, 16 bit) / ReleaseDC / 5-5-5 → 5-6-5 if needed / ret C
CalculationA field never cleared

The constructor of the calculation screen sets the selection “Ermittlung der Zahlen” (how the figures are computed) to 0, but not the “Darstellung” (display) one right next to it. With a large value, drawing the list reads past its end, the error vanishes inside the window call, and the screen stays half built and invisible. The patch clears both, in the same 11 bytes:

mov word [esi+10D48],0 / mov eax,esi  →  mov eax,esi / and dword [esi+10D46],0 / nop / nop
Picture buttonsA BITMAP never cleared

The constructor of the picture button class clears almost all its fields, but not the BITMAP (+0x7C to +0x93) that is only filled when the picture is loaded. The lineup moves “A/B” and “i” to their template position with its width and height before loading the pictures, then aligns them to the bottom right corner. With old data there the window gets huge, and the button ends up shifted or off screen. The patch clears the BITMAP too, in the same 142 bytes: the stores beyond +0x7F go through edx = this+0x80 and so need one byte of displacement instead of four.

mov [esi+A4],eax / … / mov [esi+94],eax  →  mov [esi+7C],eax / lea edx,[esi+80] / mov [edx+0…24],eax / mov [edx+30…48],eax / nop ×13
InterviewsTwo pairs that never arrive

The interview engine works on a copy of the interview context and stores the chosen answer’s two effect pairs (code, value) there. They are then applied from the context itself, whose pairs are never written: every answer applies “fans +0” twice. Two codes also don’t match the cases of the effect function: the texts use 10 for the team’s morale (no case) and 12 for a fine in DM (case 12 is the morale). The patch adds the code of A2G-Trainer’s “Wirkung der Antworten anwenden” byte for byte, so the trainer recognizes it, and sends two calls there. A fine is booked as the game books its own, on the club’s other costs. The original has no room left at the end of its code; there the exe gets a section of its own, .a2int, which goes again when the patch is taken back.

push context / call apply  →  push context / call stub+20   (pairs from the copy, 10 → 12, 12 marked as a fine)
case 12: call morale       →  call stub+C0                  (marked fine: club+38C += DM × money factor / 100)
SpeechesA warning without consequence

The check of the chosen speech decides whether it fits, takes a use and, from speech 28 on, rolls against the motivation skill. Only for a speech that works it marks the team block (+0xE5 = the number, factor +0x1C = 100), and before each strength calculation a small function applies that number’s percentages from the speech table to defence and attack and sets the hardness. The patch changes three places; the function is rewritten more compactly in its own 176 bytes, so the sign fits. It takes the table’s address from the code.

roll failed:  xor edi,edi            →  xor ebx,ebx            (as if no use was taken: no effect)
marking:      works: +E4/+E5/+1C     →  the same; doesn’t fit: +E5 = −number
effect:       percentages of +E5     →  negative number: their amounts taken off, hardness kept
Negotiation blockOne byte off

Every club keeps a counter for each human manager (+0x1081 + manager number 1–4). Each negotiation date arranged with one of its players counts it up, to at most 10; from 3 the club releases no one. The monthly club update is meant to halve the counters, but reaches one byte too low and halves +0x107D to +0x1080, so the real counters only go back to 0 at the next season. The patch moves the four loads and four stores by 4, in the same bytes:

mov cl/al/bl/dl,[ebp+107D..1080] / shr ×4 / mov [ebp+107D..1080],…  →  the same with +1081..1084
InvestmentsValue subtracted instead of deposit

The game doesn’t store the bank balance but works it out each time: the club’s ledger minus the current value of all investments plus the loans plus the season’s bookings. The ledger is never credited with the interest, so every rise of an index lowers the balance by exactly that much. Closing an investment drops the subtraction and books value minus deposit as interest on top. The patch subtracts the deposits instead of the values, in the same 48 bytes; the club’s worth stays as it was. As nothing is stored, switching it off shows the old balance again.

ledger − values + loans + bookings  →  ledger − deposits + loans + bookings
Bank balanceOne week too many

The club’s account (club +0x154, 32 bits) changes almost only once a week: at the end of the weekly booking the game adds the week’s result after tax, unchecked. Past 231 − 1 it flips to about −2.1 billion, and the bank balance with it, which the interest calculation then takes for an overdraft. The patch limits the booking to 2,000,000,000 DM. The balance shown adds the current week’s bookings and the loans; the remaining 147 million DM keep it below the limit too. An account that is higher already (set with a trainer, say) stays and only stops growing.

The booking’s 23 bytes are too few for the check. The room comes from the function for the week’s result: it adds up the same 20 fields as the bookings sum of the balance, which only subtracts the tax booked and adds one more field. Rewritten, it calls the bookings sum and takes those two back, with the same result in 29 of its 208 bytes. The check goes behind it, and the booking jumps there.

account = account + week                  →  account = account + week, at most 2,000,000,000
week’s result: 20 fields one by one (208 B) →  bookings sum + tax − field (29 B), then the check
Trainer supplyA waiting list that stays empty

Trainers and managers share one pool (trainer and manager level, the higher one is the trade); co-trainers come from it too, goalkeeper trainers have their own table. At the season change whoever is out of contract and older than 65 to 67 retires, and his place goes to the next former player on a waiting list per country group (20 places, goalkeeper trainers 10). A player only gets on it if he ends his career at 36 or later; players mostly end it only once their strength has dropped to 0. With the list empty, the retired one gets his place back: aged 30, competence 2 (goalkeeper trainers 35 and 2). Up to 44 competence grows by 1 with 20 % a season (goalkeeper trainers 50 %), so from 2 nobody gets far. The patch lowers the age to 33 and rewrites both functions shorter in their own bytes, so a roll fits. Simulated over 60 seasons, this keeps a bell around 7 to 8 with 1 to 2 % at 15; without the patch nobody is above 12 in the end.

cmp dl,23 / jbe (not on the list)           →  cmp dl,20
place back without an entry: competence 2   →  3 + 4 × random(3): 3 to 11, most often 7
Manager eventsThe table next door

The dispatcher for the manager’s private life is built from the same table as the one for another kind of events (14 pairs of weight and case). Its own table of 39 pairs lies 56 bytes behind and is used nowhere. The new cases never ran, so each was read. The honking text holds the name twice, it is passed once, and sprintf takes the caller’s saved esi as the second string: garbage or a crash.

Six cases get code of their own (MASM, tools/manager_events.asm): 13, 21, 35 and 39 have only their texts, 25 builds its message but never shows it, 34 fills the name with an empty string. The code lies in three functions nothing refers to (a news item never drawn, debug keys of the game, tab stops of a list box), the three questions behind the first part, where the question dialog reaches them. The jump table of the switch leads the six cases there. Case 34 reads the journalist’s first name from KLEINIG.SAV; the game keeps only outlet and last name.

push 6BD248 / push 0E             →  mov eax,6BD248 / add eax,38 / push eax / push 27
push name / push text / push dest  →  push name / push name / push text / push dest
jmp [eax*4+table]: cases 13, 21, 25, 34, 35, 39  →  code of their own
Most appearancesA flag nobody clears

For each human manager the game keeps two lists of 50 entries: goals and appearances, each entry with the player’s number, birth year and the flag “at the club”. With the list full, a new player replaces, from the bottom up to place 10, the first entry without the flag. A player leaving, though, clears his flag in the goals list only. The patch sets the flags of the appearances list anew from the squad and the players lent out before each count. Room comes from the sort, rewritten shorter as a bubble sort (47 instead of 139 bytes). 20 places are kept instead of 10.

start of the count: … / mov [esp+10],eax  →  … / call flags
sort: selection with three copy loops       →  bubble sort, the routine in front of it
Fish poisoningEvent 0 of the referee events

The injury is entered by a small function that only the referee events call: event 0 is the fish poisoning, event 1 the fall down the escalator (28 days, as reported). The days come from the table of injury kinds, 7 for a fish poisoning. The patch gives event 0 21 days, in the function’s bytes and five of the ten filler bytes behind it.

movzx dx,byte [eax*2+days] / mov [ecx+44],dx  →  test eax,eax / … / jne / mov dl,21 / mov [ecx+44],dx
EventsSigns, jumps and a sound

The random events book expenses at club +0x38C and income at +0x390; the hundred money events are pairs of text and amount in a table, expenses negative. The copier and the prize draw have the wrong sign there, three more events jump to the wrong booking or book the wrong field. The chocolate maker's question offers twice the amount, the booking takes the plain one; comparing the question's outcome as a byte instead of a word makes room for the doubling. Freshness goes through a function that moves it into the recovery pool for a positive value and back for a negative one; four events pass −5 and −10. A message's sound is its last argument (0 neutral, 1 positive, 2 negative).

Referee grudgeOne too many

A referee keeps the number of a club he holds a grudge against, else −1. The cards compare it with the club’s number, the match scenes with the number plus one, and there zero counts as “no grudge”. The patch drops both.

test ax,ax / je / … / inc edx / cmp eax,edx  →  test ax,ax / nop / nop / … / nop / cmp eax,edx
Event crashesA player who isn’t there

Two functions draw a player of the squad and return NULL when the one drawn has a certain flag or nobody fits. Of their 71 calls, four read the result without a test. The patch tests it at all four places, in their own bytes; pop ecx twice instead of add esp,8 makes room.

mov esi,eax / add esp,8 / cmp byte [esi+25],0A  →  pop ecx / pop ecx / xchg eax,esi / test esi,esi / je out / …
Trainer competenceA result that isn't stored

Once a year the game balances the competence of the trainers and of the managers per country group: with an average under 6 every tenth gets 1 or 2 points (at most 15), with one over 10 every tenth loses some. The raise only adds the points to the sum and counts the person at the old value again; only the cut writes the new value back. The patch writes it for the raise too, in the same 36 bytes.

new = old + bonus, sum += bonus            →  the same, plus mov [edi],ax and counting the new value
Grade averageCard and mark in one byte

For each match day a byte of the player holds the appearance (bit 7), the mark (bits 2–4) and cards (bits 0–1). The team statistics count an appearance only with a mark. The season average in the player's details and the fans' check test mark and cards together, so a short appearance with a card counts as mark 0 there.

test al,80 / je / test al,1F / je  →  test al,1C (the mark alone), in both places
Grade chartA text that isn't there

The statistics' charts load their texts from RESDLL.dll. The grade chart takes text 5800, “Formpunkte/6”, the form chart's, for its axis; RESDLL.dll has no text for marks. The patch assigns “Noten/6” from the exe, in the same 18 bytes. The string goes into the 9 NOPs behind the function's ret; its address comes from the return address of a call, so it doesn't depend on where the code lies.

push 16A8 / push ecx / call text / add esp,8  →  call $+5 / add dword [esp],5C / lea ecx,[esp+10] / call CString::operator=
TextsA section of its own in RESDLL.dll

A longer text doesn’t fit in its place. So the changed string tables and dialogs go into a new section .a2gtxt at the end of RESDLL.dll, and the resource directory points there. The section keeps which switches are on and where each resource was before; every switch builds it anew from the originals. Only texts change, as whole words: “Gruppe 1” leaves “Gruppe 10” alone. Styles and positions stay, as the game tells its picture buttons by WS_EX_CLIENTEDGE. The game reads the event texts only at exactly their length; every switch replaces whole texts and evens out the length with spaces at the end of a text. For “Innenverteidiger” the message about a new main position gets shorter: “… hat eine neue Hauptposition gelernt: Innenverteidiger.”

Quiz questionsThe sizes are in the file’s header

The manager course quiz is in TEXTE\fort.saq, the same in all three releases: the header holds the number of questions of each of the three levels, the number of texts and the length of the text block, then comes a table of where each text starts, then the block with inverted bytes. Each question is followed by its answers, separated by commas, the right one first. The game reads counts and sizes from the header, so texts may change length. “Quizfragen” replaces whole questions in their place, “Neue Quizfragen” adds questions at the end of their level; each writes the file anew independently of the other, and switched off it is the original to the byte again.

Copy protection (GOG)Eleven CD checks, ten checksums

Eleven places call a signature routine and subtract the expected value; 0 means “original CD”. GOG replaced the subtraction with NOPs, so every check fails. The patch puts in the result of a passed check. In addition, five places check a CRC32 of run.exe on disk and five a CRC32 of their own code; A2G-Patch stores the matching values after every change.

call check / add esp,4 / nop ×5  →  call check / add esp,4 / xor eax,eax / nop ×3
Patch 1.01 (GOG, 2007 CD)A new section in run.exe

The changes of 1.01 were found by comparing with the 1.01 program and the 1999 release, and rewritten in assembler (gog/a2v101.S). The code goes into a new section .a2v101 at the end of run.exe; thirteen places jump into it or change, for example the cup draw loads its MoveList.dat from the game folder instead of the CD. For the 2007 CD, msvfw32.dll puts the same code into a memory block of its own and adjusts its jumps. The three data files of 1.01 are made from GOG’s and code of our own, without any files of the patch.

Dialogs (GOG)Missing window styles

All dialogs are templates in RESDLL.dll. Compared with the 1999 file, GOG’s lacks WS_CAPTION, DS_MODALFRAME, WS_EX_CLIENTEDGE and a few more styles. The patch puts them back in place; the file keeps its size, and input and result are checked by SHA-256.

Animations (GOG)One pixel too many

The animations play in a child window exactly as large as the picture; a thread blits them into its client rect on the primary surface. GOG’s wrapper shows that rect plus one column and one row of the primary surface, where nothing was ever drawn. The patch makes the window one pixel smaller each way and blits the whole picture into it, so the extra column and row show the picture’s last ones. With a correct DirectDraw the clipper would cut them off, hence only with GOG’s wrapper.

window: add ecx,edx / add eax,edi            →  add ecx,edx / dec ecx / add eax,edi / dec eax
blit:   call GetClientRect(window, dest)     →  call CopyRect(dest, source)
Mouse clicks (GOG)One bit of the driver’s capabilities

GOG’s wrapper puts Direct3D 9 under DirectDraw. Setting up the device, it keeps bit 9 of D3DCAPS9.PrimitiveMiscCaps (D3DPMISCCAPS_CLIPTLVERTS) and clips by itself without it. Current drivers don’t report the bit; the delay was found by A3-Rework, a patch for Anstoss 3, whose GOG wrapper has the same code. The patch keeps 1, at both places. The wrapper keeps its name, so the patch for the animations still recognizes it.

shr eax,9 / and eax,ebp  →  mov eax,1
msvfw32.dllA proxy for the 2007 CD

msvfw32 isn’t a KnownDLL, so the copy in the game folder wins. All 47 exports jump on to the real DLL, which is loaded only on the first call. A thread waits until the unpacked code is in memory and then writes only the enabled patches. Built without the C runtime so that it loads on Windows 2000 and XP too.
