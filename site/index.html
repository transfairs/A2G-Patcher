Für Anstoss 2 Gold · Original, GOG & 2007er-CD

Anstoss 2 Gold,
wie es sein sollte.

Ein kleines Fenster, acht Haken: Die Pfeilknöpfe zählen wieder weiter, die Videos zu WM, EM und Finale lassen das Spiel nicht mehr abstürzen, nichts friert nach langer Windows-Laufzeit ein, der Ton kommt aus dem richtigen Gerät, und wer mag, hebt die Torgrenzen auf. Ohne Kompatibilitätsmodus, jederzeit rückgängig zu machen.

Herunterladen Alle Versionen

Windows XP (SP3) bis 11 · .NET Framework 4.0 oder neuer · GPL-3.0

01Die Patches

Fehlerbehebung

Pfeile zählen beim Gedrückthalten weiter

Unter aktuellem Windows zählen die Pfeilknöpfe bei Zahlenwerten nur ein, zwei Schritte und bleiben dann stehen. Bisher half nur der Kompatibilitätsmodus „Windows 98“. Mit dem Patch zählen sie einfach weiter.

Fehlerbehebung

Kein Absturz bei den Videos zu WM, EM und Finale

Nach dem WM-Titel stürzt das Spiel ab, weil Windows das Videoformat von WM.AVI, EM.AVI und FINALE.AVI nicht mehr kennt. Der Patch überspringt das Video, das Spiel läuft weiter. Mit installiertem Indeo-Codec laufen die Videos wie gewohnt.

Fehlerbehebung

Kein Einfrieren nach über 24 Tagen Windows-Laufzeit

Eine Wartepause von 3 Sekunden wird zu Wochen, sobald Windows länger als 231 ms läuft. Das kommt schneller als gedacht: Der Schnellstart von Windows setzt die Laufzeit beim Herunterfahren nicht zurück.

Fehlerbehebung

Ton über das Standard-Audiogerät von Windows

Das Spiel nimmt das zuletzt gefundene Soundgerät statt des eingestellten. Mit Monitor-Lautsprechern und Headset landet der Ton so leicht auf dem falschen. Mit dem Patch kommt er dort heraus, wo Windows ihn hinschickt.

Fehlerbehebung

Keine falsche Warnung „Festplatte fast voll“

Den freien Platz rechnet das Spiel mit 32 Bit aus. Auf großen Platten läuft die Rechnung über, und beim Speichern erscheint ab und zu grundlos die Warnung, die Festplatte sei fast voll.

Fehlerbehebung

Kader nicht über 30 Spieler wachsen lassen

Ein Verein mit ausgeliehenen Spielern kann einen 31. Spieler bekommen, der Daten hinter dem Kader überschreibt. Der Patch zählt bei der Prüfung „Kader voll?“ auch die tatsächlichen Spieler.

Fehlerbehebung

Desktop-Auflösung auch nach einem Absturz zurückholen

Das Spiel stellt den Bildschirm so auf 640×480 um, dass die Umstellung einen Absturz überdauert. Mit dem Patch stellt Windows die Auflösung selbst wieder her, sobald das Spiel endet. Die GOG-Version macht das schon richtig, dort ist der Haken ausgegraut.

Fehlerbehebung

Vereinsnamen bei der Pokalauslosung richtig darstellen

Unter aktuellem Windows und unter Wine erscheinen die Vereinsnamen im Video der Pokalauslosung doppelt so breit, halb so hoch und gepunktet, weil das Spiel ein Bild mit 16 Bit pro Pixel erwartet und 32 bekommt. Der Patch holt das Bild ausdrücklich mit 16 Bit.

Optional

Torgrenzen aufheben

Das Spiel lässt eine Mannschaft nur treffen, solange sie bis zur Halbzeit unter 6 und danach unter 10 Toren liegt, und halbiert ab 7 Toren ihre Chancen. Der Patch hebt die Grenze auf 15 an und streicht die Bremse.

02So geht’s

  1. Spiel beenden.A2G-Patch ändert nichts, während Anstoss 2 läuft.
  2. A2G-Patch.exe starten.Von wo auch immer. Es schlägt den eigenen Ordner und die installierte CD- und GOG-Version vor, „Durchsuchen …“ wählt einen anderen Spielordner.
  3. Haken setzen, „Übernehmen“.Gewünschte Patches anhaken, nicht mehr gewünschte abhaken. Fertig.

Was dabei passiert

Original (1999)anstoss2.exe

Die Spieldatei wird direkt geändert. Vorher legt A2G-Patch eine Sicherung anstoss2.exe.vor-a2g-patch daneben. Sind alle Patches wieder abgehakt, ist die Datei Byte für Byte wie vorher und die Sicherung verschwindet.

GOGrun.exe

Genauso, mit run.exe.vor-a2g-patch. Eine Dateiprüfung in GOG Galaxy stellt das Original wieder her; dann einfach noch einmal übernehmen.

2007er-CDrun.exe (gepackt)

Der Programmcode liegt nur verschlüsselt auf der Platte. A2G-Patch legt deshalb eine msvfw32.dll in den Spielordner, die bei jedem Spielstart den Code im Speicher ändert. Alle Patches abhaken löscht sie wieder.

03Gut zu wissen

Warum fragt A2G-Patch nach Administratorrechten?

Liegt das Spiel unter „Programme“, darf dort nur ein Administrator schreiben. A2G-Patch bietet dann an, sich selbst als Administrator neu zu starten.

Mein Virenscanner meldet die msvfw32.dll.

Manche Scanner schlagen bei einer unsignierten DLL im Spielordner an, die so heißt wie eine System-DLL; Schadsoftware nutzt denselben Trick. Die DLL reicht alle Aufrufe an die echte msvfw32.dll von Windows weiter und ändert nur den Code des Spiels. Der Quellcode liegt offen in dll/msvfw32.c.

Ein Haken ist ausgegraut.

Jeder Patch sucht seine Stellen anhand der Befehle drumherum. Findet er sie nicht genau einmal, im Original- oder im gepatchten Zustand, bietet A2G-Patch ihn nicht an, statt blind etwas zu überschreiben.

Liegt schon eine andere msvfw32.dll im Spielordner?

Eine DLL, die nicht von A2G-Patch stammt, wird nie angefasst. Eine aus einer anderen Version von A2G-Patch wird beim „Übernehmen“ ersetzt.

Verträgt sich das mit A2G-Trainer?

Ja. Der Schalter „Spielmechaniken“ im A2G-Trainer hebt die Torgrenzen auf, solange der Trainer läuft, und erkennt, wenn A2G-Patch das schon dauerhaft erledigt hat.

04Unter der Haube

Für Neugierige: Was genau im Maschinencode passiert. Dieselben Muster gelten auf der Platte (Patches.cs) und im Speicher (dll/msvfw32.c).

PfeileEin Wettlauf zwischen zwei Threads

Beim Gedrückthalten schickt ein Thread alle 60 ms einen Schritt ans Fenster, aber nur, solange keiner aussteht (+0xF4 == 0). Als ausstehend markiert er den Schritt erst nach PostMessageA. Unter Windows NT ist das Fenster oft schneller, findet beim Abarbeiten noch eine 0, und danach schreibt der Thread eine 1, die nie wieder abgebaut wird. Der Patch markiert den Schritt vor dem Senden, in denselben 41 Bytes:

; vorher
mov eax,[msg] / mov ecx,[esi+1C] / push 0 / push 0 / push eax / push ecx / call ebx
mov eax,[esi+F4] / mov [esi+F0],60 / inc eax / mov [esi+F4],eax
; nachher
mov [esi+F4],1 / mov [esi+F0],60
mov eax,[msg] / mov ecx,[esi+1C] / push 0 / push 0 / push eax / push ecx / call ebx
nop / nop / nop / jmp next
VideosEin fehlender NULL-Check

Die Videos sind Indeo 3.2, das aktuelles Windows nicht mehr dekodiert. Der Videospieler des Spiels prüft das Ergebnis von AVIStreamGetFrameOpen nicht und liest dann durch einen NULL-Zeiger. Der Patch ergänzt die Prüfung und nimmt bei NULL den Weg, den das Spiel ohnehin bei einer fehlenden Datei geht. Den Platz dafür schafft eine kompaktere Kodierung der Befehle davor, in denselben 75 Bytes:

push [edi] / call AVIStreamGetFrameOpen / test eax,eax / jnz ok
mov [edi],eax / jmp release   ; Video überspringen
ok: mov [edi-8],eax
TorgrenzenZwei Bremsen in der Spiel-Engine

Die Grenze wird zu einem festen Wert, die Halbierung wird übersprungen. Mehr als 15 geht nicht: Ergebnis und Halbzeitstand speichert das Spiel als 4-Bit-Wert pro Mannschaft.

limit:  setg r8 / dec r32 / and r,-4 / add r,10  →  setg r8 / mov r32,15 / nop …
brakes: jle (7E)                                  →  jmp (EB)
EinfrierenEin Vergleich mit Vorzeichen

Eine Antwortsequenz wartet bis zu 3 Sekunden und vergleicht dazu die Differenz zweier timeGetTime-Werte mit Vorzeichen. Läuft Windows länger als 231 ms, wird die Differenz negativ, und Sleep bekommt eine riesige Wartezeit. Der Patch vergleicht ohne Vorzeichen, an beiden Stellen:

sub eax,[ebp+17C] / cmp eax,0BB8 / mov [ebp+17C],eax / jge (7D)  →  jae (73)
SoundgerätDie falsche GUID

Beim Aufzählen merkt sich das Spiel das Gerät mit den meisten 3D-Puffern. Seit Vista melden alle dort 0, bei Gleichstand gewinnt das letzte, und dessen GUID geht an DirectSoundCreate. Mit NULL nimmt DirectSound das Standardgerät von Windows:

push &guid (68 xx xx xx xx)  →  push esi / nop ×4   ; esi ist hier 0
Platz-WarnungEin 32-Bit-Überlauf

Das Spiel multipliziert die Werte von GetDiskFreeSpaceA in 32 Bit. Auf großen Platten ist das Ergebnis der freie Platz modulo 4 GB und liegt ab und zu unter der Schwelle von 1,5 MB. Der Patch überspringt die Warnung, gespeichert wird ohnehin:

cmp eax,177000 / jae (73)  →  jmp (EB)
KaderLeihen zählen als Abgang

Ob ein Kader voll ist, prüft das Spiel vielerorts nur anhand einer Prognose, in der ein ausgeliehener Spieler als Abgang zählt. So passt ein 31. Spieler hinein, der hinter die 30 Plätze geschrieben wird. Der Patch prüft zusätzlich die tatsächliche Kadergröße, in denselben 32 Bytes der Funktion:

voll = Prognose >= 30  →  voll = Prognose >= 30 oder Kader >= 30
AuflösungEin fehlendes Flag

Das Spiel ruft ChangeDisplaySettingsA mit Flag 0 auf, die Umstellung ist dann nicht an den Prozess gebunden. Mit CDS_FULLSCREEN gilt sie nur fürs Spiel, und Windows stellt die Auflösung zurück, wenn es endet, auch nach einem Absturz:

mov [esi+1C8],ebx (Feld ist schon 0)  →  mov byte [esp+4],4 / nop
msvfw32.dllEin Proxy für die 2007er-CD

msvfw32 ist keine KnownDLL, also gewinnt die Kopie im Spielordner. Alle 47 Exporte springen an die echte DLL weiter, die erst beim ersten Aufruf geladen wird. Ein Thread wartet, bis der entpackte Code im Speicher liegt, und schreibt dann nur die aktivierten Patches. Ohne C-Laufzeit gebaut, damit sie auch unter Windows XP lädt.
